# BITSkrieg Writeups

Challenge writeups from the BITSkrieg mentor group.

## How to submit

1. **Fork** this repo.
2. Copy [TEMPLATE.md](TEMPLATE.md) to `writeups/<challenge-name>.md` and fill it in.
3. Put any screenshots in `writeups/images/` and link them like `![step 1](images/step1.png)`.
4. Commit, push to your fork, and **open a pull request**.
